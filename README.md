# Kinal APP
Esta aplicacion realiza un venta de productos que genera una venta y 
y una venta detallada, se registra un usuario o es un cliente.

## Tecnologias utilizadas 
* **java 21**
* **Spring Boot 4.0.2**
* **Maven** (Gestor de dependencias)
* **MySQL** (Sistema gestor de base de datos)

## Requisitos Previos
Antes de ejecutar la aplicacion, debe tener instalado: 
* JDK 17 o superior 
* Maven instalado
* Una instancia activa en MySQL
